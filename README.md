# Интернет-магазин Криволесье

## Описание проекта

Интернет-магазин мерча. Пользователи могут просматривать каталог, искать товары, фильтровать и сортировать их, добавлять товары в избранное и корзину, оформлять заказы и просматривать историю покупок.

Реализованный функционал:
- Каталог товаров с фильтрацией и поиском.
- Корзина и избранное с сохранением данных для авторизованных и неавторизованных пользователей.
- Регистрация и авторизация пользователя.
- Для авторизованных пользователей предусмотрено управление профилем. Неавторизованные пользователи могут пользоваться корзиной и избранным с сохранением данных на стороне браузера (localStorage).
- Оформление заказов и сохранение истории заказов.
- Адаптивная вёрстка для мобильных устройств и десктопов.
- Интеграция с Supabase для работы с базой данных, авторизацией и хранением изображений.

## Установка и запуск

### Требования

- Node.js
- npm

### Установка

Клонировать репозиторий:

```bash
git clone https://github.com/Sorkan176/krivolesye.git
```

Перейти в директорию проекта:

```bash
cd krivolesye
```

Установить зависимости:

```bash
npm install
```

Создать файл `.env` в корне проекта и указать переменные окружения Supabase:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

### Запуск в режиме разработки

```bash
npm run dev
```

### Сборка проекта

```bash
npm run build
```

### Предварительный просмотр сборки

```bash
npm run preview
```

## Используемые технологии

- **React** — разработка пользовательского интерфейса.
- **JavaScript** — основная логика приложения.
- **Vite** — сборка и запуск проекта.
- **React Router** — маршрутизация.
- **CSS** — стилизация и адаптивная вёрстка.
- **Supabase** — база данных, авторизация и хранение изображений.
